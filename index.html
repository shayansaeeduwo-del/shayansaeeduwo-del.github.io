AthletiQ

Founder and developer · Nov 2025 – present

A mobile app that turns a student-athlete's program and sport into a personalized weekly plan for training, classes, and study, then points them to nearby tournaments and events that fit their goals.

  • Email sign-up with deep-link confirmation, routing new users to onboarding and returning users home
  • Four-step onboarding (academic profile, athletic profile, goal weighting) with drafts saved on-device
  • Schedule generation with the Claude API, returning a colour-coded week rendered on a 7-day calendar
  • Supabase backend with row-level security on profiles, schedules, onboarding, and performance logs
  • React Native
  • Expo
  • TypeScript
  • Supabase
  • PostgreSQL
  • Claude API
